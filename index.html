0.4What are agents?

Agents in one minute

What are agents?

A tailored Copilot experience, purpose-built for your business.

Agents look and feel like Copilot, but they:

  1. Tailor the experience to a specific use case
  2. Focus on the data (inside or outside Microsoft 365) that’s most relevant to your business needs
  3. Can be equipped with skills to send emails, update records, or open support tickets
Today in Agent Builder: points 1 and 2 — instructions + your SharePoint/OneDrive sources. Point 3 (actions) needs Copilot Studio → S8, 18 Nov.

3.1Good sources

Before you add a single file

Good sources make a good agent

1️⃣

Current · one version only

Remove drafts and old FAQs. Two versions of one product sheet = two possible answers.

2️⃣

Owned · kept up to date

Prefer files with an owner and a review date — usually a SharePoint library over a personal copy.

3️⃣

Concise · well structured

Clear headings and numbered sections help the agent cite precisely. Excel: keep the data in one sheet.

4️⃣

Permitted · users can open it

The agent answers each person only from sources they are allowed to open.

5️⃣

Fit for the agent’s audience

Pick files everyone who uses the agent is allowed to see, in line with BSI data classification. Product sheets, policies and SOPs you know well are a great start.

6️⃣

Ready · upload the day before

New files can take several minutes to be ready. Put them in OneDrive or SharePoint early.

3.3Permissions & labels

Protection comes with you

Link your files — don’t re-upload them

✅ Recommended today · reference files in OneDrive / SharePoint

  • The agent respects existing permissions and sensitivity labels
  • Each user only gets answers from files they can open
  • Update the file — the agent picks up the change

⚠ Use with care · upload files into the agent

  • Anyone who can use the agent can see answers from those files
  • Labels with user-defined permissions or extract rights disabled → agent creation fails, without an error message
  • Password-protected or double-key-encrypted files can’t be used
If “Create” fails silently: remove uploaded files with a protective label and link them from OneDrive / SharePoint instead.

4.4Six blocks of instructions

Instructions

Six blocks of good instructions

1 · PurposeOne sentence: who it serves and what it does.
2 · RulesTone, language, sources to use, what to do when unsure.
3 · StepsNumbered only when order matters. One action per step.
4 · TermsDefine your vocabulary: MMQ, ujrah, rahn, nisbah.
5 · OutputFormat and length: “max 5 bullets + a Source line”.
6 · Self-check“Before answering, confirm every point has a source.”

Do

  • Say what to do, with precise verbs: search, quote, ask
  • Use Markdown headings and bullets
  • Name the sources: “Use the files in S5 Produk Fiktif”

Avoid

  • Vague verbs: “handle”, “process”
  • Two tasks in one step
  • Leaving tone and length to chance

    W.2Four rules

    Using agents responsibly

    Four rules behind every agent today

    1

    Your sources, your permissions

    The agent sees only what each user can open.

    Knowledge is linked from OneDrive / SharePoint, so labels and access rights still apply.

    2

    Cite or say “not found”

    No source, no answer.

    Every answer ends with “Source: document, section”.

    3

    Prepare, don’t decide

    Financing, legal and Sharia decisions stay with people.

    The agent declines approvals and refers akad questions to the Sharia compliance team.

    4

    An owner and a review date

    Policies change — so must the agent.

    Owner reviews sources every quarter or when a policy is reissued.
